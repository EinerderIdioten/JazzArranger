# 10首ABC盲测和声对照记录

日期：2026-08-12  
范围：HH001 - HH010  
任务：C-centered ABC melody -> harmony spans  

## 结论先行

这组结果说明，我对爵士和声词汇是有的，但稳定性不够。主要问题不是“不会写7和弦”，而是会把功能骨架写歪，尤其在：

- 过度使用 `7` / `7b9` / 其他 altered dominant
- 把应当保留的功能链改成泛化的 `ii-V-I` 模板
- 对 split-bar、终止式、转位、借和弦的处理不稳
- 在小调和长段落里，root 结构漂移明显

因此，这批样本更支持一个判断：`1.7B` 小模型有价值，但应当做候选生成器或快速 proposer，不适合直接端到端定稿。

## 反思

这次输出的核心失误不是“偶发错几个和弦”，而是模型习惯把复杂语法压成更常见的 jazz 模板。于是会出现：

1. 本该是明确属功能的位置，被写成 `min7`
2. 本该保留的半小节结构，被整段替换
3. 本该尊重旋律终止的地方，被过度加花

换句话说，我更像是在生成“像爵士的和声”，而不是“对这条旋律最合适的和声”。

## 结论

如果目标是做一个可用系统，小模型仍然值得做，但要放在更强的约束后面：

- 小模型负责提候选
- 大模型或 critic 负责功能校验和重写
- 最后再做 rerank / 约束修正

不建议直接把 `1.7B` 当最终定稿器。它能学到爵士 extension 的外形，但要稳定守住功能和声，还差一个显式的评审层。
